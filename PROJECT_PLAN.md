# TOPBOX SUPPORT OS — План разработки и внедрения

Система контроля качества VPN-продукта и омниканальной техподдержки на 40 000 пользователей (Telegram + Instagram, OpenRouter AI, 5 уровней аналитики ITSM, ролевая админка).

---

## 1. Архитектура и уровни системы

### Уровень 1. Классификация обращений
- **10 обязательных категорий**:
  - 🔴 `Не подключается` (приложение, ключ, сервер, оператор, устройство)
  - 🟠 `Медленно` (оператор, сервер, Wi-Fi, приложение)
  - 🟡 `Не работает конкретный сайт` (блокировка, DNS, маршрут, сайт)
  - 🔵 `Не умеет подключить` (инструкция, установка, настройка)
  - 🟣 `Проблема с приложением` (вылетает, не открывается, ошибка)
  - ⚫ `Ограничения оператора` (мобильная сеть, Wi-Fi, регион)
  - 💳 `Оплата` (оплата, продление, возврат)
  - 🔑 `Подписка` (ключ, тариф, срок, активация)
  - 🟢 `Всё исправлено` (проблема решена)
  - 🔴 `Не решено` (требует инженера)
- Дополнительные теги и признаки.

### Уровень 2. Паспорт обращения (7 обязательных полей + метаданные)
1. `User ID` (внутренний ID абонента / Telegram / Instagram)
2. `Устройство / Платформа` (iPhone, Android, Windows, Mac, Linux, Router, Другое)
3. `Оператор` (МТС, Мегафон, Билайн, Tele2, Ростелеком, Wi-Fi, Другой)
4. `Приложение` (Incy, Outline, v2rayNG, Happ, V2RayTun, Shadowrocket, Streisand, Karing, Другое)
5. `Проблема` (текст / симптом)
6. `Причина` (блокировка оператора, сбой сервера, ошибка ключа, баг приложения, DNS и др.)
7. `Результат` (решено сменой протокола, перевыпущен ключ, отправлена инструкция, эскалировано инженеру и др.)
- Метаданные: время создания, время первого ответа (FRT), время решения (MTTR), оператор, повторное обращение (`is_reopened`), помогла ли инструкция (`instruction_helped`), эскалация инженеру (`escalated_to_engineer`), критичность (`P0` — авария, `P1` — крит. индив., `P2` — стандарт, `P3` — вопрос/FAQ).

### Уровень 3. Метрики относительно всей базы (40 000 пользователей)
- Общая база: 40 000 пользователей (настраиваемая величина).
- Статусы: Нормально работают (%), Были проблемы (%), Неизвестный статус (%), Неактивны (%).
- `User Problem Rate`: Уникальные пользователи с технической проблемой / Активная база.
- Ключевые показатели поддержки (Support Score):
  - FRT (First Response Time)
  - Resolution Time (MTTR)
  - FCR (First Contact Resolution %)
  - Reopen Rate (%)
  - CSAT (%)
  - Automation Rate (% решено без участия человека)
  - Deflection Rate (% решено инструкциями/ботом)
  - Escalation Rate (% переданных инженеру)

### Уровень 4. Рейтинг причин и периодическая отчётность
- ТОП проблем за день / неделю / месяц с динамикой (% изменения к прошлому периоду).
- Генератор отчетов в один клик:
  - Ежедневный срез (5-минутный отчет для руководства).
  - Еженедельный отчет `VPN — Support Weekly`.
  - Ежемесячный `Customer Experience / Product Quality Review`.

### Уровень 5. Drill-Down аналитика и Problem Register (ITSM/ITIL)
- Многомерный срез аномалий: Категория ➔ Платформа ➔ Оператор ➔ Приложение ➔ Сервер/Протокол.
- Автоматический детектор корреляций (например, выявление паттерна: «Android + МТС + Incy = 380 обращений»).
- Реестр проблем (`Problem Register`):
  - Связь Incident ➔ Problem ➔ Product Backlog.
  - Оценка эффекта: предотвращение обращений, сэкономленные часы саппорта.
- Product Backlog с приоритизацией на основе реальных жалоб.

## 2. Модули системы

### Модуль 1. Ядро данных и Backend API (FastAPI + SQLite/PostgreSQL)
- Модели: `User`, `Ticket`, `Message`, `TicketPassport`, `ProblemItem`, `BacklogItem`, `KnowledgeArticle`, `Setting`, `AuditLog`.
- Сервис авторизации JWT с 4 ролями (`support_agent`, `support_lead`, `director`, `superroot`).
- Статистический движок для расчета метрик 40 000 базы, drill-down и генерации отчетов.

### Модуль 2. Омниканальный интеграционный слой (Telegram + Instagram)
- **Telegram бот** (@topvpnhelp_bot совместимый):
  - Интеграция с форумной супергруппой операторов (message_thread_id).
  - Контроль рабочих часов (09:00 - 20:00 МСК) с антиспам-кулдауном.
  - Автовыдача ключа по regex-триггерам.
  - Интерактивный визард самодиагностики (выбор устройства, оператора, проблемы).
- **Instagram Direct**:
  - Вебхук для приема сообщений (`/api/webhooks/instagram`).
  - Адаптер отправки ответов (Meta Graph API / симулятор для тестирования).
  - Единая лента сообщений независимо от источника.

### Модуль 3. AI-движок (OpenRouter + Пул бесплатных моделей)
- Пул бесплатных моделей:
  - `google/gemini-2.0-flash-exp:free`
  - `meta-llama/llama-3.3-70b-instruct:free`
  - `mistralai/mistral-small-24b-instruct-2501:free`
  - `deepseek/deepseek-r1:free`
  - `qwen/qwen-2.5-72b-instruct:free`
  - и др.
- Автоматический failover: при 429 / 503 запрос мгновенно переключается на следующую модель.
- 3 режима ИИ:
  1. `Auto-Triage`: автоматическое распознавание типа проблемы, оператора, устройства и заполнение паспорта тикета.
  2. `AI Copilot`: предложение готового качественного ответа оператору по базе знаний.
  3. `Auto-Reply`: автоматический ответ на типовые вопросы (P3 FAQ) при включенном режиме автопилота.

### Модуль 4. Интеграция с базой VPN и управление ключами
- Адаптер подключения к базе данных основного VPN-сервиса (PostgreSQL / SQLite мок-режим).
- Просмотр действующих ключей пользователя (протокол, сервер, трафик, срок).
- Экшены оператора: «Отправить ключ», «Пересоздать ключ (Reset Key)», «Отправить инструкцию».

### Модуль 5. Ролевой интерфейс (Admin Web Panel)
- **Экран Директора**: «VPN HEALTH», 40k база, метрики здоровья, ТОП проблем, реестр проблем, продуктовый бэклог.
- **Экран Руководителя саппорта**: контроль очереди, SLA, оценка операторов, база знаний, генератор отчетов.
- **Экран Оператора саппорта**: рабочая область чатов (TG + IG), паспорт тикета, быстрые ответы, ИИ-подсказки, кнопки ключей.
- **Экран Суперрута**: системные настройки, токены TG/IG, ключи OpenRouter, пользователи и роли.

### Модуль 6. Тестирование, сид-данные и Docker-развертывание
- Сид реалистичных данных (тикеты, статистика 40 000 базы, реестр проблем, статьи базы знаний).
- Модульные тесты бэкенда (API, аутентификация, аналитика, OpenRouter fallback).
- Dockerfile и docker-compose.yml для продакшена.
